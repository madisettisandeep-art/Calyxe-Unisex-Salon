## 🌟 Overview

**Calyxé Unisex Salon** is a state-of-the-art web application and digital flagship experience designed for one of Telangana's most prestigious salons. Built with a bespoke **Alabaster Porcelain & Champagne Gold** luxury light palette, it combines editorial aesthetics with smooth, interactive 3D elements.

### ✨ Key Features

- **12-Scene Cinematic 3D Walkthrough Engine**: Interactive scroll-driven walkthrough across all salon zones powered by Three.js ambient particles and optical zoom transitions.
- **Luminous Light Design System**: Alabaster porcelain surfaces, crystal glassmorphism (`backdrop-blur-xl`), hairline antique gold borders, and deep obsidian typography.
- **Day / Night Luxury Switcher**: Seamless theme switcher between Radiant Day and Haute Night modes.
- **Interactive Before & Beyond Slider**: Real-time draggable before/after transformation comparison showcase.
- **Curated Service Menu**: Categorized portfolio spanning Hair, Skin & Beauty, Grooming, Spa / Relaxation, Transformations, and Bridal Rituals.
- **Concierge Booking Desk**: Integrated appointment reservation desk with real-time field validation and direct WhatsApp booking confirmation.
- **Ambient Acoustic Soundscape**: Custom synthesized warm 432Hz harmonic audio ambience.
- **Verified Google Ratings & Accolades**: 4.9★ social proof display and client testimonials.
- **Full SEO & Schema.org Structured Data**: Local business JSON-LD markup, OpenGraph cards, and Twitter summary metadata.

## 🛠️ Technology Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with bespoke luxury tokens & Vanilla CSS Glassmorphism
- **3D Graphics & Particles**: [Three.js](https://threejs.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Motion**: [Framer Motion](https://www.framer.com/motion/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/madisettisandeep-art/Calyxe-Unisex-Salon.git
   cd Calyxe-Unisex-Salon
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Open your browser:
   - Navigate to [http://localhost:3001](http://localhost:3001)
